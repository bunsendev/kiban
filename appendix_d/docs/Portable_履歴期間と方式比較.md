# 履歴期間と方式比較（pilot.45）

現場画面の末尾「履歴期間と予測方式の比較」を開きます。日常の4ステップ操作とは別の、IT担当者向け機能です。

1. 比較履歴を選んで「結果を表示する」を押します。
2. 方式ごとの平均誤差（MAE）と割合誤差（WAPE）を確認します。小さいほど誤差が小さく、件数が少ない結果は慎重に扱います。
3. 商品・倉庫IDで検索し、履歴開始・終了、観測日・欠損日を確認します。
4. 「季節性と評価条件」で起点・条件・月別の指標を確認します。

新規比較は出荷CSVを含むZIP、または正式取込済み日次データから作成します。原本の数量単位と過去の利用可能時刻の仮定を確認してください。未承認PDFを実績として取り込みません。数量が空欄の日やファイルのない日を自動で0にはしません。

選定期間で方式を選び、別の検証期間で確認します。検証結果を見てから方式を選び直した数値を「改善」とは扱いません。3年方式でも実際の履歴が3年未満なら、その存在する期間だけを使用します。

比較結果が良くても現場の予測モデルは自動変更されません。単位未確認は採用保留です。確認済みでも既存の候補承認・適用とロールバック手順を経てください。比較用原本はData/State/HistorySources、結果はData/State/HistoryStudiesに保存します。業務実績や元の予測値を上書きしません。
