# 手書き・左右2表の読取改善（pilot39）

今回の対象：JANラベルの誤割当、根拠のない年、倉庫列・右表の欠落、掛算・追記の意味が不明な数量。

1. 担当者画面でPDF・画像を登録し、照合するJANマスター版を選択します。
2. 読取欄で「手書きの左右2表を拡大して読む」を選びます。左右に別の表がある手書き帳票用です。通常の印刷在庫PDFは従来の「API不要」を使ってください。
3. 原本送信に同意して、ページごとにAI読取を実行します。全体概要・左拡大・右拡大の3画像を1回のAPI呼出しで送ります。中央は10%重ねて切れを減らします。画像入力量が増えるため料金が増える場合があります。
4. 一覧のJAN・倉庫・日付・数量を原本と確認します。選んだマスターで一意に照合できる商品候補は端末内で補完します。マスターはAIに送りません。
5. 右表や倉庫列の未取得、同内容の重複候補を画面に表示します。重複を自動削除しません。不完全な場合は確認済み範囲と理由を指定して採用します。
6. 読取済みのページを改善方式で読み直す場合は「指定ページを再読取する（追加料金）」を使います。確認済み原本は再読取せず既存の訂正手順を使います。

JANに24TV等のラベル・不正なチェック桁が入った場合は原記載を保持してJAN候補を保留します。短いJANはマスターの下6桁と照合し、一意の候補だけ補完します。商品名候補と下6桁が矛盾する場合は自動補完しません。

左右読取では日付の根拠原文も取得し、4桁年を含む同じ年月日を確認できない値は保留します。倉庫名を原記載と照合し、出荷・在庫の見出しが混在する場合は種類を確認待ちにします。原記載・AI値・修正値を区別し、年・拠点名を創作しません。年不明の日付は担当者が確認して一覧で入力してください。

数量の掛算式・取消線・追記・丸囲みで単位や最終値が不明な場合、数量・ボール・バラ・入数を保留します。一般の手書き表の空欄を0にはしません。全行に原記載と参照領域を表示し、元PDF・画像は変更しません。元AI抽出はページ別・再読取履歴に保持します。

機能と保留ルールを人工帳票で検証しています。根拠原文もAI抽出のため、それだけで正確性を保証しません。実手書きPDFの新モデル比較と担当者が確認した正解による一致率測定は未実施です。人間確認・正式採用の手順は省略しません。
