# Phase 2S JAN対応表取込

## 目的

Phase 2Rで出力したJAN記入用CSVを画面から取り込み、在庫商品コードをJANへ接続するための
不変な対応表として安全に保存する。

## 検査

- UTF-8 CSV、5 MiB以下、1〜10,000行
- 列は`商品コード`、`商品名`、`JAN`、`確認メモ`の固定順
- 商品コードの重複、在庫に存在しないコード、在庫商品の不足
- JANの空欄、8桁または13桁、EAN check digit
- 対象在庫商品の全件充足

一つでも問題がある場合は`CORRECTION_REQUIRED`と件数を返し、対応表を保存しない。全条件を
満たした場合だけ`READY`とし、正規化済みCSVのSHA-256から`product-jan-<sha256>`を発行する。
同じ内容の再登録は同じIDとなる。

## 保存境界

対応表は管理対象入力root内の`product-jan-mappings`へatomic保存する。この領域はGitと配布ZIPの
対象外である。APIレスポンスには商品コード、商品名、JAN、確認メモを返さず、件数とIDだけを返す。

## 画面

`/ui/intake`でJAN対応診断後、記入済みCSVを選択して検証・保存できる。不備があれば未記入、
形式不正、重複、対象外、不足の件数を表示する。
