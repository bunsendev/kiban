# 担当者向けかんたん予測画面

## 目的

現場担当者が、APIやmapping、job、Workerなどの仕組みを意識せず、予測に使うデータを選んで分析を開始できる入口を提供する。

## 現在の実装範囲

`/ui/easy`で次を提供する。

1. 初回接続コードの入力
2. PC上のCSV・ZIP選択、または管理対象フォルダー内のCSV選択
3. ファイル名、サイズ、更新日時の確認
4. CSVヘッダーと登録済み列mappingの自動照合
5. mappingドライランjob、またはZIP一括検証batchの登録
6. 操作手順、所要時間、成功・失敗種別を操作改善台帳へ記録

元ファイルは変更・上書きしない。接続コードはブラウザーの保存領域へ永続化せず、画面メモリ内だけで使用する。
操作記録にはファイル名、path、ファイル内容、接続コード、自由入力を含めない。画面上でも収集範囲を確認できる。

## 操作設計

- 画面ごとの主要操作を1つにする。
- 担当者向けの表現では、mapping ID、job ID、Workerなどの内部用語を表示しない。
- 修正が必要な場合だけ、次に行う操作を日本語で示す。
- 管理者用の詳細操作は既存の`/ui/intake`へ分離する。
- 画面上部に「データを選ぶ → 内容を確認 → 予測を実行 → 結果を見る」の現在位置を表示する。

## 次の画面

次の実装単位は、分析結果を件数、期間、対象商品数、要修正項目に絞って示す「内容を確認」画面とする。担当者の確認後にだけ予測を開始し、誤操作による実行を防ぐ。
