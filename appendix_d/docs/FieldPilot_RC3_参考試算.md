# Field Pilot RC3 商品別参考試算

配布版: `0.1.0-field-pilot.3`。RC2の投入・確認・フィードバックに、商品別の参考試算とその結果へのフィードバックを追加する。現場で使いながら判断条件を版付きで蓄積するための配布版である。

操作順: データ投入 →「投入したファイルを確認」→ 管理画面 `/ui/pilot/settings` でJAN候補を原本と照合して保存 → 確認済み商品を選び「出荷数量・欠落日の参考試算条件」を保存 →「参考予測を開始」→ 倉庫別の7日間の参考値と不足理由を読む → 選択式フィードバックを記録。訂正時は条件を新版として保存して同じ商品を再試算する。

数量の解釈は箱・くくり・パレット・混在・不明から選べる。単一単位と判断された商品でも原本数量を箱へ換算しない。欠落日は「観測日だけを使う」または「他商品の出荷行がある日だけ当該商品をゼロと仮定する」から選ぶ。出荷ファイル自体がない日はゼロにしない。単位が不明・混在する商品、JAN矛盾、読取不能な原本、履歴不足は理由付きで数値試算を保留する。過去の原本だけなら「過去データの再現」と表示する。

試算は原本数量の28日移動平均で、正式な予測Run、在庫接続、出荷推奨ではない。現場の判断を自動確定せず、結果へのフィードバックと条件の訂正を残す。既存の現場データ・設定を保った更新手順とRC2の運用境界は [RC2体験運用](FieldPilot_RC2_体験運用.md)を参照する。
