# Windows Portable 実データPreflight・参考バックテスト結果

判定日: 2026-09-30。対象branch: `codex/data-b-preflight`。

## 目的

Portable P1の人工CSV専用画面へ、現場で受け取った在庫・出荷ZIPを原本のまま投入し、正式採用前の分析と短い参考バックテストまでを接続した。PostgreSQLを含むPortable P2、正式な日次build、OSS比較、現在の補充推奨は本変更に含めない。

## 実装

- ZIPを100 MB、5,000 member、展開後1 GiBまでに制限し、暗号化、重複名、絶対path、親移動を拒否する。
- UTF-8 BOMまたはCP932の在庫・出荷CSVだけを対象とする。
- 出荷日は行値を使用し、13桁JAN・非負数量を自動確定する。12桁JANは確認待ち、不正行は隔離する。
- 在庫の商品コードは、同じZIPの出荷JANと一致した13桁だけを自動確定する。賞味期限欠損は確認待ち、不正コード・数量は隔離する。
- 自動確定した出荷を拠点×JAN×日へ決定的に集約し、`Data/Prepared`へ保存する。
- 拠点ごとの直近35日が揃う場合、最初の28日で既存`builtin-baseline/seasonal_naive_7`を学習し、続く7日のMAEとWAPEを参考表示する。
- 原本ZIP、分析JSON、日次集計、結果を`Data`配下へ分離し、実値をログへ出さない。
