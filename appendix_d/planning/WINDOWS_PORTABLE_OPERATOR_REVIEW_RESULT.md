# Windows Portable 担当者確認・判断再利用 実装結果

判定日: 2026-09-30。対象branch: `codex/data-b-preflight`。

## ゴール

実データ事前分析で見つかった確認待ち・隔離を、開発者へ戻さなくても現場担当者が画面で確認できるようにする。確定できるデータだけで参考予測へ進み、判断を次回投入へ再利用する。

## 操作フロー

1. 在庫・出荷ZIPを分析する。
2. 「確認が必要なデータ」で原因、元の値、商品名、対象行数を確認する。
3. 13桁JANへの対応付け、賞味期限欠損の確認、または今回の予測対象からの除外を選ぶ。
4. 必要なら判断メモと「同じ値を次回も使用」を指定して保存する。
5. 自動判定OKと確定済み出荷だけを再集計し、参考バックテストを実行する。

未確認項目が残っていても、未確認行を予測へ混ぜずに確定済みデータだけで処理を続けられる。

## 保存契約

- 原本ZIP: `Data/Input/<analysis_id>.zip`
- 不変の分析結果: `Data/Analysis/<analysis_id>.json`
- 初回日次集計: `Data/Prepared/<analysis_id>.csv`
- 判断反映後の日次集計: `Data/Prepared/<analysis_id>-reviewed.csv`
- 分析別の追記判断履歴: `Data/Decisions/<analysis_id>.jsonl`
- 次回再利用するJAN対応付け: `Data/Decisions/rules.jsonl`

判断を変更しても過去行は削除・上書きせず、新しい判断を追記する。API表示と再集計には最新判断を使用する。
