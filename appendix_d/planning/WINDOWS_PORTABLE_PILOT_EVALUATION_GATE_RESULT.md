# Windows Portable Pilot評価Gate 実装結果

## 完了したこと

- `PILOT_ACTIVE`の適用計画と固定済みRuntime週次評価を結ぶ、改変検知可能な評価証跡を追加した。
- 評価基準版、観測日数、共通Actual件数、Runtime未特定率、MAE、WAPE、担当者修正率、欠品、期限切れ、倉庫間移動の上限を固定できる。
- 業務KPIはBaselineと候補版で一致した同一Actual集合から集計し、各値の取得件数が共通Actual件数に満たない場合は合格させない。
- 担当者が継続、停止、Baselineへ戻す依頼、正式採用審査への送付を理由付きで追記できる。合格前の正式採用審査送付は拒否する。
- 評価時のPilot開始GateイベントとRuntime週次評価をhashで固定し、変更・破損を再読込時に検知する。
- Windowsの長いパス制限を避ける短い監査ファイル名と、revision単位の排他的な新規作成を実装した。
- API、担当者画面の手順15-3、回帰試験を追加した。

## 自動化しないこと

評価結果だけで正式設定、候補版の配置、Pilot停止、受入、rollbackは実行しない。担当者の判断後、既存の承認・適用Gateで別操作として実施する。

## 次工程

現場Pilotで週次の同一Actualを蓄積し、評価基準版の閾値を業務責任者が確定する。その後、合格した候補版を既存の受入Gateへ送り、正式採用またはrollbackを実機で検証する。
