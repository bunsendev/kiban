# 3年履歴の利用調査と比較実装（2026-10-20）

## 結論と採用判断

**更新：2026-10-20、ユーザーより過去CSVの「数量」もボール（CASE）と確認。末尾の再評価が最新。初回の単位未確認比較は履歴として保持。**

現行の正式日次作成は365日で切り捨て、標準モデル seasonal_naive_7 は渡された全期間の平均ではなく、直近4週内で最初に見つかる同曜日を使っていた。正式日次入力を3暦年上限へ拡張し、期間別5方式と現行方式を同じ対象で比較できる機能を追加した。既存の標準モデルは維持する。

実データでの条件付き比較では、選定期間だけで商品・倉庫ごとの方式を決めた結果のholdout MAEは328.72、現行は370.65（11.31%減）。ただし単位未確認・利用可能日時の仮定・古い履歴という制約があり、本番精度改善の保証でも採用承認でもない。単位が確認されても、現在の業務期間での追試と既存の候補承認・適用ゲートを必要とする。全商品に3年平均を採用する判断はしない。

## 1. 調査した経路

- CSV/PDF受付 → 確認・正式取込 → formal_forecast_pipeline → formal_shipment_daily → forecast_batches → forecast.py → builtin-baseline → 保存・表示。
- 正式取込済みPDFからの数量と原本照合条件は変更しない。未承認PDFを過去実績に流用しない。
- 日次作成の実際の開始計算が origin−364日だったため修正。3暦年前の翌日から起点日まで、存在する履歴だけを使用する（最大1096日）。既存の28日/7日評価条件、在庫基準日整合性は維持。
- forecast.py は標準モデルを維持し、明示的な候補モデル指定を追加。旧モデル候補のCPU-small上限400日は維持し、長期モデルだけ1096日の別プロファイルとする。
- 出荷のみの参考需要経路 reference_demand は引き続き28日。全経路を一律に3年化したとは扱わない。
- 過去の予測履歴を上書きしない。新規Production receiptには入力期間・日次件数・モデル版を保存し、旧receiptの再表示互換性を維持。比較明細は各予測点に実際の参照開始/終了・件数を記録する。

## 3. 比較条件と結果

14日先、28日間隔の13起点。2024-08-13〜2025-07-15。最初9起点を選定、最後4起点（2025-04-22/05-20/06-17/07-15）をholdout。各起点までの実績かつknown_at以前のみを入力。全6方式が計算可能で実績がある同じ商品日だけを採点。各方式の選定6,609件、holdout2,425件、明細計54,204件。

|---|---:|---:|---:|---:|
|現行・前週同曜日|448.91|370.65|23.35|-39.67|
|28日同曜日平均|409.61|354.30|22.32|-50.96|

MAE=絶対誤差平均。WAPE=絶対誤差合計÷実績数量合計×100、分母ゼロは算出不可。偏りが正なら予測過少、負なら予測過大。数量指標の単位は未確認の原本数量単位。ゼロ実績は採点し、欠損実績は採点しない。

90日方式がholdoutで最良だからと事後に選び直さない。商品ごとに選定期間だけで方式を固定したholdout集計はMAE328.72、WAPE20.71%、偏り21.55、2,425件。季節性は2年分の十分な月次観測と再現性がある場合だけ適用し、他は直近28日へ戻す。月別精度・商品倉庫別の改善/非改善・曜日/月/年平均・欠損数は私有JSONと比較画面で確認可能。

## 4. 追加した機能と再現性

- /history-studies：履歴ZIPまたは正式日次データで比較。原本数量の単位と日時仮定を明示確認。検索とページ送りで全商品を確認。
- historical CSV adapterは比較専用。正式実績・在庫・予測への自動登録なし。JANチェック、数量欠損、倉庫不明、重複競合を隔離。
- history_algorithmsは既存Providerへ5モデルを加算。既存モデルの出力・Provider版を維持、新モデルID/計算版はv1。
- normalized input hash、設定・起点・評価時点・原本provenance hashで比較IDを固定し、結果JSONに改ざん検知hashを保存。再実行で過去結果を上書きしない。
- 商品単位の採用候補は十分な選定と4×14日のholdout、MAE/WAPE両方の改善を要求。単位未確認はKEEP_BASELINE。確認済みでもREVIEW_REQUIREDであり自動採用なし。
