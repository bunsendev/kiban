# Windows Portable 現場導入・受入手順

担当者はコマンド操作を行いません。管理担当者が配布ZIPのSHA-256と端末の実行許可を確認し、書き込み可能なPC内フォルダーに展開します。USB上やZIP内から直接実行しません。初回は付属人工データで技術確認し、合格後に管理担当者の立会いで業務ZIPを投入します。

## 担当者の操作

1. 配布ZIPを右クリックして［すべて展開］を選び、展開先の `ブンセン予測を起動.cmd` をダブルクリックします。小画面とブラウザーが開くことを確認します。起動しない場合は時刻、画面のエラーコード、`Data/Logs` を管理担当者に伝えます。
2. ブラウザーで［付属の人工CSVで試す］を押します。別の方法を確認する場合は、`Sample/synthetic_shipments.csv` を選択し［予測を開始］を押します。
3. 「予測が完了」と14行（2系列×7日）の結果を確認します。［結果JSONを保存］と「過去の結果」も確認します。`Data/Results` に結果が保存されます。
4. 小画面の［終了］を押し、アプリを再起動します。「過去の結果」で先ほどの結果を開きます。同じ人工CSVをもう一度実行して結果が同じことを確認します。実行IDは毎回変わります。
5. 業務データ確認では画面からZIPを選ぶか、［投入フォルダを開く］から`Data/Incoming`へZIPをコピーします。分析、未確定情報の確認、正式取込、予測、SHADOW推奨の順に進めます。未確定値を推測や0で補完しません。

## 管理担当者の記録

端末名、Windows版、利用者権限、試験日時、ZIPのSHA-256、起動/終了時間、結果件数、エラーコード、配布フォルダーのサイズ、`Data` のサイズを記録します。実行時のCSV本文や数量を障害報告へ貼り付けません。確認前後の `Data` は削除せず、アプリの更新時も `App` だけを交換します。

| Gate | 確認方法 | 結果 |
| --- | --- | --- |
| 1 Dockerなし | Docker未導入の端末で起動 | 未確認 / PASS / FAIL |
| 2 WSLなし | WSL未導入の端末で起動 | 未確認 / PASS / FAIL |
| 3 Pythonなし | Python未導入の端末で起動 | 未確認 / PASS / FAIL |
| 4 コマンドなし | 担当者がダブルクリックから終了まで操作 | 未確認 / PASS / FAIL |
| 5 Baseline | 人工CSVで14行の予測を表示 | 未確認 / PASS / FAIL |
| 6 保存 | `Data/Results` と履歴を確認 | 未確認 / PASS / FAIL |
| 7 再起動 | アプリ終了・再起動後に履歴を開く。可能ならPC再起動も確認 | 未確認 / PASS / FAIL |
| 8 正常終了 | ［終了］後に不要なPortable processがない | 未確認 / PASS / FAIL |
| 9 異常終了 | 管理担当者が中断試験後に再起動し、成功履歴を保持 | 未確認 / PASS / FAIL |
| 10 オフライン | 管理担当者が外向き通信を遮断した状態で一連操作を確認 | 未確認 / PASS / FAIL |
| 11 localhost | 管理担当者が待受先 `127.0.0.1` のみを確認 | 未確認 / PASS / FAIL |
| 12 既存版 | 開発側がDocker版の回帰試験を確認 | 未確認 / PASS / FAIL |

全12 GateがPASSするまではP1を完成扱いにしません。特に現場端末の実行ポリシーによりEXEが拒否された場合は、Defender・SmartScreen・AppLocker・WDACを無効化せず、管理担当者が許可方法を確認します。異常終了試験と外向き通信の遮断は管理担当者が担当します。

## 複数PCへ配布する場合（0.6.0-pilot.3）

同じ未使用ZIPを各PCの書込可能なローカルフォルダーへ展開してください。初回起動で「現場利用」または「IT動作確認（テスト）」と端末名を入力します。閉じると設定せず終了します。用途と端末IDはData/State/installation.jsonへ保存され、用途は変更しません。ITのテスト履歴を現場へ移さないため、使用済みフォルダーやDataを別PCへ複製しないでください。別用途は元のZIPを新しいフォルダーへ展開してください。

画面上部に用途・端末名・アプリ版・端末IDが表示されます。起動ログにも用途と端末IDが残ります。判断・学習は各PCのData内だけで実行され、PC間の同期はありません。個別の結果ファイルだけを集約すると端末情報が失われるため、問い合わせ時はinstallation.jsonとLogsを組にしてください。自動集約・端末管理サーバーは今回の対象外です。

バックアップはアプリを終了してData全体をPC別に保存します。同じ端末の復元だけに使用してください。更新はバックアップ後にAppを差し替え、Dataを保持します。Portable版の自動更新は未検証のため手動更新です。現場PCの実行許可は各PCで確認してください。
