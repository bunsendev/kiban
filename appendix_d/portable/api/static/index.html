ブンセン予測

ファイルを分析し、確認が必要なデータを分けてから参考予測を検証します。

1. 在庫・出荷ZIPを分析

在庫CSVと出荷CSVをまとめたZIPを選択してください。原本を変更せず、JAN・数量・賞味期限と予測可能な期間を確認します。

未選択

ZIPを選択してください。

0自動判定OK
0分析時の確認対象
0分析時の隔離対象

    2. 確認が必要なデータ

    候補を確認して判断を保存してください。元ファイルは変更せず、判断は履歴へ追記します。

    この分析の判断履歴

      3. 確定済みデータで参考予測を検証

      未確認項目が残っていても、自動判定OKと担当者が確定した出荷データだけで実行します。

      4. 最新在庫を正式取込用に準備

      各倉庫の最新在庫だけを対象に、拠点・基準時刻・箱（CASE）の確認を記録します。未解決行がある倉庫は正式取込へ渡しません。

      5. 試験対象を正式在庫Workerで検証

      倉庫ごとに10〜20商品を試験対象として確認します。候補は自動選択されていますが、正式採用は確認後に行います。

        6. 出荷履歴を確定して14日予測

        承認済み在庫と同じJAN・倉庫の出荷履歴だけを日次化します。出荷CSV自体がない日は欠測のまま保持します。

        7. 正式予測を更新

        確認済み系列だけを既存の予測Runへ登録します。確認が必要な系列は除外理由を残し、0として扱いません。
