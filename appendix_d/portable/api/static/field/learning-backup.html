学習データのバックアップ・復元

担当者画面へ

確認・修正履歴、JAN対応、除外設定、学習・比較データ、元ファイル、予測結果をまとめて保存・復元します。

1. 再インストール前に保存

分析・取込が終わってから押してください。ZIPはアプリのフォルダ以外（USBメモリなど）にも保存してください。業務データを含むため大切に保管してください。

2. 再インストール後に復元

保存したバックアップZIP、または旧版のData-backup.zipを選びます。既存データに足し込まず、バックアップ時点の内容に置き換えます。現在のDataは復元前に別フォルダへ退避します。

予約後はデータ変更を停止します。ブラウザだけでなくブンセンのランチャーを終了し、もう一度「ブンセン予測を起動.cmd」を実行してください。次の起動時に復元し、この画面に結果を表示します。

3. 復元結果



APIキーと送信用TokenはこのZIPに含めません。再インストール先で保存状態を確認し、必要なら再設定してください。端末ID・ログ送信設定は現在のPCの設定を維持します。


バックアップを作る前に失われたデータは復元できません。現在より新しいアプリで作ったZIPは、先にアプリを更新してから使用してください。
